## What Is This?
A  commitment** to solve **one problem every single day** using **C++**.

This repository is both:
-  A **personal discipline challenge**
-  A **community space** to discuss, learn, and grow together

> The goal is not speed.  
> The goal is **consistency and clarity of thinking**.

---

##  Challenge Rules
- **Duration:** 1 full year
-  **Daily Task:** Solve **1 problem**
-  **Language:** C++
- **Consistency is mandatory**
-  **Sunday Rule:**  
  - Sundays is off day , only revision  *

---

## Community & Discussion
This is an **open learning community**.

You are encouraged to:
-  Discuss solution approaches
-  Share optimized or alternative methods
-  Talk about edge cases and mistakes
-  Ask questions and review code
-  Learn by explaining to others

 Discussions happen via:
- GitHub Issues  
- Pull Requests  
- Code Reviews  

Anyone serious about **problem solving and growth** is welcome.
